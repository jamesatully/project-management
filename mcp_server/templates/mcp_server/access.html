Other MCP clients (.mcp.json style)

{
  "mcpServers": {
    "projecthub": {
      "type": "http",
      "url": "{{ mcp_url }}",
      "headers": {"Authorization": "Bearer {{ new_key|default:'<your token>' }}"}
    }
  }
}

Keep tokens out of files you commit; most clients can read the header value from an environment variable.
